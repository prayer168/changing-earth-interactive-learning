# 設計規格

## 使用者

國小高年級學生與自然科學教師。

## 視覺原則

- 使用自然地景色彩，但避免單一色系壟罩整體畫面。
- 文字以短段落呈現，主要操作按鈕達到觸控尺寸。
- 教材以固定頁籤列切換單一學習面板，不使用長頁式導覽。
- 頁籤可橫向捲動，手機版改為直向排列。

## 互動設計

- 地表作用觀察：切換風化、侵蝕、堆積，立即改變 SVG 地形、圖層標示與回饋文字。
- 互動實驗圖解需提供可觀察證據，不使用只有單一山丘或單一河流的籠統圖示。
- 災害配對：支援拖曳與點選，兼顧滑鼠、觸控與鍵盤使用。
- 板塊 SVG 動畫：依序呈現推擠、能量累積、斷層錯動與震波傳播，提供播放、暫停、重播與速度調整。
- 闖關題：逐題作答、即時解釋、最後給分數與複習建議。

## 無障礙

- 使用語意化 HTML 與 `aria-label` 標註 SVG。
- 所有互動按鈕可鍵盤聚焦。
- 不只靠顏色傳達狀態，並搭配文字回饋。
