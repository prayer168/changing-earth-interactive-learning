# 變動的大地

「變動的大地」是給國小五年級自然科學使用的互動式數位教材，主題包含我們的大地、地表的變化與大地的災害。學生會透過圖解、操作模擬、情境配對與闖關題，理解地表如何因自然作用逐漸改變，並把防災知識連結到日常生活。

## 教材資訊

- 適用對象：國小五年級
- 科目：自然科學
- 學習時間：40 分鐘
- 教材模式：引導模式
- 目前版本：v1.0.1
- GitHub Pages：https://prayer168.github.io/changing-earth-interactive-learning/

## 學習目標

- 認識山地、河流、平原、海岸等常見地形。
- 說明風化、侵蝕、搬運與堆積如何造成地表變化。
- 理解地震、山崩、土石流等大地災害與環境條件的關係。
- 能根據情境判斷風險，提出合宜的防災行動。

## 教材特色

- 七個頁籤式學習段落，適合電腦、平板與手機。
- SVG 地景圖、地表作用圖層與板塊推擠步驟動畫。
- 地表作用切換觀察、災害風險拖曳配對。
- 10 題素養導向闖關題，題庫獨立存放於 `data/quiz.json`。
- 使用 `localStorage` 記錄學習進度。
- 自主學習資源附來源類型、適用年級與檢核日期。

## 頁籤內容

1. 學習任務：建立三個核心問題。
2. 原理探索：說明地形、地表作用與災害風險。
3. 互動實驗：切換地表作用並完成災害配對。
4. 動畫模擬：播放板塊推擠與震波示意。
5. 生活應用：連結河岸、海岸、山路、豪雨、地震與坡地社區。
6. 闖關大挑戰：完成 10 題理解、應用與推理題。
7. 自主學習：延伸到政府、科學館與研究機構資源。
